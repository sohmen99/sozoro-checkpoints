# そぞろ チェックポイント盤

**混雑エリアから人を外側へ誘導するためのチェックポイント網。88地点。**

▶ **https://sohmen99.github.io/sozoro-checkpoints/**

「上野周辺のおすすめスポット一覧」ではありません。**空間設計が先、店は後**です。
どこにチェックポイントが必要だったか → その周辺に何があったか → 何を選んだかが、
同じ `checkpoint_id` で追跡できます。

---

## 順番

```
1. 混雑コアを面として定義        1.55 km²
2. 外周から徒歩7分刻みの等時線     7 / 14 / 21 / 28 / 35分
3. 店名を見る前に仮チェックポイント  88点（全方位10〜13）
4. 既存185件から品質基準を抽出     Q1〜Q5（位置情報は一切見ない）
5. 仮点の周辺380mから候補を集める   5,751件
6. 位置適合度 × 品質適合度で選定    88/88 割当
```

## 1. 混雑コア（上野駅一点にしない）

上野公園・東京国立博物館・国立西洋美術館・上野の森美術館・上野動物園・不忍池・上野駅・
アメヤ横丁・御徒町駅・上野広小路・京成上野駅 の**11地点の溜まりを面で結んだ 1.55 km²**。

人流オープンデータ（国交省 1kmメッシュ）も当てましたが、**この縮尺では解けませんでした。**
上野公園の値は周辺の中央値より低く出ます（メッシュは月次の滞在人口で、緑地は住民・就業者が
少ないため）。輪郭は地点から起こし、メッシュは検証に留めています。

## 2. 徒歩7分刻みの等時線

**直線の同心円ではありません。** OpenStreetMap の徒歩ネットワーク
（節点198,151・辺244,232）を組んで、コア内の6,137節点を0分としたダイクストラで
到達時間を出しています。速度80m/分。

だから川・線路・大きな敷地は**橋や踏切のあるところしか通れず**、等時線がそれに沿って歪みます。
到達できた面は41.8km²。

## 3. 仮チェックポイント（店名を見る前）

各帯を方位順に周回し、**760m間隔**で節点に置きました。

| 帯 | 仮点 |
|---|---:|
| 7分 | 9 |
| 14分 | 13 |
| 21分 | 18 |
| 28分 | 22 |
| 35分 | 26 |

方位の分布は **北10 / 北東13 / 東10 / 南東11 / 南13 / 南西10 / 西11 / 北西10**。

## 4. 185件から抽出した品質基準

**所在地・方角・上野からの距離・町字・区は分析から除外**しています。見たのは業種と名前だけ。

| | 基準 | 根拠 |
|---|---|---|
| **Q1** | 名物の一皿がある業種 | 飲食88件が6業種に87件集中。うなぎ20% / そば18% / ラーメン12% / お好み焼き12% / すし9% / とんかつ8%。**居酒屋1,093件・軽食喫茶965件・中華315件からは0件** |
| **Q2** | 支店ではない単店の屋号 | 「〇〇店」で終わる名前は **採用1% / 見送り24%（倍率0.05）**。すしざんまい・くら寿司・スシローは全部見送り |
| **Q3** | 短い和の屋号 | 5文字以下が採用58% / 見送り42%。「屋」で終わるものは倍率2.22 |
| **Q4** | 訪ねられる寺社・史跡そのもの | 文化財97件のうち寺40・院16・庵3・神社2で61件（63%） |
| **Q5** | 「もの」ではなく「場所」 | 185件に美術工芸品10件が混入（坂本村文書・杮経・稲垣利兵衛家文書など）。**採用傾向ではなく採り間違いなので除外条件として立てた** |

総合品質 = Q5 ×（0.40·Q1 + 0.28·Q2 + 0.14·Q3 + 0.18·Q4）

## 5〜6. 候補探索と選定

仮点から**半径380m**の候補5,751件を採点し、`品質 × (1 − 0.35·(距離/380)²)` で選びました。
**半径いっぱいの候補は品質で約1.5倍ないと勝てない**効き方です。
指示どおり、50m先の弱い候補より120m先の良い候補を採ります。

結果は **88/88 割当・平均ズレ126m・最大266m・平均品質0.95**。
185件からの再利用は6件、新規が82件です。

### チェーンの扱い

**屋号の多店舗検出だけでは足りませんでした。** 母数が台東区内に偏っているので、
区外に何十店もある系列でも「区内に1店」なら単店に見えます。実際、最初の出力には
舎鈴・五ノ神水産・まぐろ人・卍力・用心棒が残っていました。

いまは既知チェーンの名簿で落としています（回転寿司・ラーメン・そば・とんかつ・
ファストフード）。あわせて、フードコートや「拉麺劇場」のような**店ではない箱**も外しました。

それでも外から系列か単店か判断できない屋号が残るので、**`needs_check` 列に「要確認」の
印を付けてあります（15件）。** 落とさずに印だけ付けるのは、誤って良い老舗を切るほうが
損だからです。地元を知っている人が見て決めてください。

## 確認したこと

| | 結果 |
|---|---|
| 特定方向への偏り | 8方位に10〜13。偏りなし |
| 各帯の地点数 | 7分9 / 14分13 / 21分18 / 28分22 / 35分26 |
| 15±7分の連鎖 | **88/88 が3つ以上つながる**（最小6・中央12・最大18）。実際の道のりで測定 |
| 内側から外への3連鎖 | **91% 成立**。終点は21分帯140 / 28分帯639 / 35分帯1,046 |

## ファイル

| | |
|---|---|
| `checkpoints.csv` | 88行27列。仮プロット・最終スポット・Q1〜Q5・採用理由・次点3件・出典 |

### 作り直す

```sh
python3 tools/01_core.py       # 混雑コアの面
python3 tools/02_isochrone.py  # 徒歩ネットワークで等時線
python3 tools/03_bands.py      # 帯を輪郭に
python3 tools/04_checkpoints.py# 仮チェックポイントを置く
python3 tools/05_criteria.py   # 185件から品質基準
python3 tools/06_assign.py     # 候補探索と選定
python3 tools/07_verify.py     # 連鎖の検証
python3 tools/08_db.py         # データベース
python3 tools/09_map.py        # マップ
```
